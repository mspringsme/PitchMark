## Essential missing captures

Only six additional screenshots are needed to complete the main story cleanly:

1. **Clean calling screen before selection** — Coach mode, no modal, full screen.
2. **Pitch selected** — the same screen with `Curve` selected and no location selected.
3. **Pitch and location selected** — same state and framing, ideally Curve low-and-away.
4. **Called code/display** — large code shown clearly after the call.
5. **Live sharing pair** — owner invite/join state and the second-device live display.
6. **Runner advancement** — before and after states using the same batter/game.

Matching framing between screenshots 1–3 is important. After Effects can then create a seamless button pulse, dim, strike-zone expansion, and label sequence without visible jumps.

## Continuity notes

- The new captures consistently feature **Hadley vs. Knights**, which is good. Use that story throughout the final edit.
- Counts and totals vary as the game progresses; that is natural for the statistics section.
- Avoid mixing these with older **Juju** screenshots in the same continuous sequence unless they are presented as a clearly separate game.
- `IMG_3383.PNG` through `IMG_3385.PNG` include an `App Store` return indicator. Crop or mask it for marketing use; recapturing without it would be cleaner for an App Store preview.
- Battery level and capture time change throughout the set. A phone-frame crop can hide the status bar in the marketing film. For the App Store preview, use a consistent status-bar treatment or recapture the hero sequence in one session.
